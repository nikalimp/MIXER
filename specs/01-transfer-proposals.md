### 2.1 Игра «Сведи трек» — механика (черновик)
```
[Старт] клик «Сведи трек» ──► звук разрешён, дека A: LOBODA играет
   │
   ▼
[Отсчёт] таймер в центре: время до «boom boom» ──► за 3 с — пульс свитчера
   │
   ▼
[Сведение] клик по свитчеру ──► оценка попадания
   │            ├─ ±0,25 с — «Идеально»
   │            ├─ ±0,6 с  — «Чисто»
   │            └─ дальше  — «Мимо» → «Ещё раз»
   ▼
[Переход] кроссфейд 0,5 с на деку B: sidodgi — «boom» ──► счёт + CTA «Пробное занятие бесплатно»
```
1. **Вертушки.** Две деки внизу hero, вид сверху, SVG по CDJ-2000NXS2 из оборудования школы: джог-колесо с дисплеем, Play/Cue. Без логотипа Pioneer. Пластины крутятся, пока трек играет.
2. **Скретч.** Зажал джог и тянешь — звук идёт за пальцем: скорость и направление = движение. Отпустил — трек продолжается с места. Звук назад — заранее развёрнутый буфер.
3. **Таймер.** Крупные цифры по центру между деками: «00:07.4» до момента сведения. Под ним — подсказка «Жми на словах boom boom».
4. **Свитчер.** Кроссфейдер-кнопка снизу по центру. Клавиша Пробел — то же действие.
5. **Темп.** LOBODA ≈ 117,5 BPM, sidodgi ≈ 129 BPM. Дека B стартует с темпом, подогнанным под A (playbackRate ≈ 0,91), и за 4 такта выходит на свой. Это и есть «сведение».
6. **Фрагменты.** На сайте — только фрагменты по 20–30 с, без возможности скачать файл целиком.
7. **Без звука и движения.** До клика — статичный кадр. `prefers-reduced-motion` — без вращения. Телефон — та же игра, кнопки крупнее.
8. **Точки треков (Ник, 2026-11-11):** смена трека — на 0:40 трека LOBODA; sidodgi играет с начала (0:00). Файл sidodgi на самом деле AAC/MP4 с расширением .mp3 — конвертируем сами.

### 2.2 Раздел «Полезное»
- Страница `/materials/` и блок-превью на главной (3 карточки + «Все материалы»).
- Карточка: название, тип (сэмплы, чек-лист, пресеты, гайд), описание в 1–2 строки, кнопка «Скачать» или «Открыть».
- Ребята добавляют материал без программиста: одна строка в `src/content/materials.ts` через веб-интерфейс GitHub (или файл в `content/materials/`). Инструкция — в передаче.
- Файлы — по внешним ссылкам (Яндекс Диск, Google Drive) или в `public/files/`.
- Без регистрации. Опция на потом: выдача файла за контакт (лид-магнит) — P1.
