1. Время блокировки 420 мс: Метрика с Вебвизором блокирует основной поток примерно на 470 мс (third-party) — на тестовом домене без Метрики было 99.

**site-audit:**

- Must «нет `publish.json`» — подтверждается: паспорта публикации в репозитории нет. Нужен `web:sync`.
- Must «заявки не уходят» — ложное срабатывание: секреты приходят из GitHub в `api/lead-secrets.php` при сборке, файл на сервере есть (403).
- Should «счётчик Метрики не найден» — ложное срабатывание: счётчик 114227234 стоит в `src/content/site.ts` и есть в HTML боевого сайта. Аудит не понимает запись `isStaging ? 0 : 114227234`.

Плана статей нет — правок плана нет. Предложения Нику:

1. Создать в Метрике 114227234 две цели «JavaScript-событие»: `lead_form` и `lead_game`.
