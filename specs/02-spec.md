### 7.1 Игра «Сведи трек»
- **Место:** нижняя часть hero, под CTA. Две деки по мотивам CDJ-2000NXS2 (вид сверху, SVG, без логотипа Pioneer), между ними — таймер, снизу по центру — свитчер (кроссфейдер).
- **Сценарий:**
  1. Статичный кадр, кнопка «Сведи трек ▶». Звук не грузится до клика.
  2. Клик: дека A — LOBODA feat. Pharaoh «Boom Boom» с 0:00 (фрагмент 0:00–0:50). Дека B готова: sidodgi, duboshit «boom» с 0:00.
  3. Таймер считает до 0:40 трека A. За 3 с — свитчер пульсирует.
  4. Клик по свитчеру (или Пробел): дека B стартует с 0:00, кроссфейд 0,5 с, дека A затихает.
  5. Оценка по моменту клика относительно 0:40: ±0,25 с — «Идеально», ±0,6 с — «Чисто», раньше или позже — «Мимо» + «Ещё раз». Не нажал до 0:45 — «Упустил момент».
  6. После сведения: B играет фрагмент 0:00–0:30, затем экран «Сводить по-настоящему — на пробном занятии» → `#form`.
- **Темп:** A ≈ 117,5 BPM, B ≈ 129 BPM. B стартует с playbackRate ≈ 0,91 и за 8 с выходит на 1,0.
- **Скретч:** зажал джог (мышь или палец) — дека этого трека идёт за движением: скорость и направление по углу поворота, назад — развёрнутый буфер. Отпустил — играет дальше с той же точки.
- **Таймер:** мм:сс.д до момента сведения, подпись «Жми на словах boom boom».
- **Техника:** Web Audio API, свой код без библиотек; аудио — AAC/MP3 фрагменты ≤ 1 МБ каждый, грузятся после клика; без возможности скачать файл ссылкой.
- **Доступность:** все кнопки с клавиатуры, `aria-live` для таймера и оценки (раз в секунду, не чаще), `prefers-reduced-motion` — без вращения пластин. Тач-цели ≥ 44 px.
- **Без JS:** H1, текст и CTA hero видны; игры нет.
- **Производительность:** код игры грузится отдельно после первого экрана; LCP — текст H1.
