## 2. Направление — прототипы до кода
На ECO-PRO и URALDOMA стиль меняли 5 раз уже после сборки. Поэтому выбор делается **на этом этапе, на прототипах, а не на готовом сайте**:
1. Разбор 5–10 референсов (Behance, шаблоны Tilda, сайты из брифа): что берём из каждого — одной строкой.
2. 2–3 быстрых прототипа **главной** в разных концепциях из [[Дизайн-концепции]] (HTML-страница или Claude Design, не Figma-детализация; скилл `web:variants`). Есть брендбук или дизайн-система клиента — все прототипы строятся только по ним, [[Дизайн — предпочтения Ника]] не применяются и не сравниваются. Нет брендбука — направление A по предпочтениям Ника, B (и C) — в другом характере.
3. Клиент (в ускоренном режиме — Ник) выбирает одно; дальше — токены и шаблон услуги.
У переноса — одно направление: токены снимаются с текущего сайта, прототип показывает «то же, но чище».

## 6. Изображения, фото и видео
Стиль обработки фото задаётся здесь, до сборки — потом все фото обрабатываются по нему одним проходом (стандарт §6 «Фото, видео, карты»).
- **Фото команды / объектов:** кадрирование (вертикаль 4:5 / горизонталь 3:2), цвет (как есть / ч/б / тонирование в цвет бренда), фон (как есть / вырезан — лёгкой моделью rembg), зерно, скругление 4–8 px.
- **Оригиналы** — в `media/` (или `materials/source-media/` для снятых со старого сайта); на сайт — WebP 1440 и 720 px с подписью-alt.
- **Видео первого экрана:** до 3 МБ, постер, без звука, без автозапуска на мобильных.
- **Логотип** — SVG (светлая и тёмная версии), **фавикон** — из логотипа. Без SVG логотипа этап не начинается: запрос в `requests.md` с пометкой «блокирует этап 4».
